# Backend Development Learning Workspace

This repository contains my backend development practice workspace. It includes a full backend project along with supporting folders where I learned and practiced core backend concepts, API development, server-side programming, and basic deployment workflows.

The main goal of this workspace is to document my journey from learning backend fundamentals to building a more complete backend application.

## Folder Structure

```txt
Backend Dev/
  MegaBackendProject/
  Learning Backend/
  Basic Deployment/
```

## MegaBackendProject

`MegaBackendProject` is the main project in this workspace.

It is a YouTube-style video app backend built with Node.js, Express.js, MongoDB, Mongoose, JWT authentication, Multer, and Cloudinary.

### Key Concepts Covered

- REST API architecture
- User authentication and authorization
- JWT access and refresh tokens
- Password hashing with bcrypt
- MongoDB schema design using Mongoose
- File upload handling with Multer
- Cloudinary media upload integration
- Protected routes using middleware
- Modular route-controller-model structure
- Video, user, comment, like, playlist, tweet, and subscription models
- Backend structure for a scalable video-sharing application

### Main Features

- User registration and login
- Secure password storage
- Access token and refresh token flow
- Avatar and cover image upload
- Channel profile API
- Watch history model
- Video API foundation
- Comment, like, playlist, tweet, and subscription modules
- Dashboard API foundation

This project represents the practical implementation of the backend concepts I learned in the other folders.

This folder helped me understand the practical steps required to make backend services accessible online.
